============================================================
How To Start MediaPipe on Raspberry Pi4
============================================================
# Run image_classification.
# mediapipe
sudo pip3 install mediapipe

cd mediapipe-samples/examples/image_classification/raspberry_pi
wget -O classifier.tflite -q https://storage.googleapis.com/mediapipe-models/image_classifier/efficientnet_lite0/float32/1/efficientnet_lite0.tflite

python3 classify.py
