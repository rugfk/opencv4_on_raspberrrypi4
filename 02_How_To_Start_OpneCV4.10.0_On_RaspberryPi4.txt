=======================================================
How To Start OpenCV samples on Raspberry Pi4:
=======================================================
# Check Version
pkg-config --modversion opencv4
# Check libraries.
pkg-config --libs --cflags opencv4

cd opencv-4.10.0
cd samples
cd python

# Run facedetect.py
python3 facedetect.py
